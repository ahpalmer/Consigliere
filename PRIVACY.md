# Privacy Policy

_Last updated: 2026-10-27_

Consigliere is a personal, self-hosted assistant run by a single operator for their own use. It is not offered to
the public, and it has no other users.

## What it accesses

- **Google account data:** read-only access (the `gmail.readonly` scope) to one dedicated mailbox owned by the
  operator. That mailbox exists only to receive notification emails the operator forwards to it. Consigliere cannot
  send, delete, or modify email, and it does not access any other Google account or any other Google data.
- **Messages sent to the assistant** through the operator's own chat app.

## How data is used

- Notification emails are read to pull out the structured details they contain, which are stored and summarized
  for the operator.
- Email content and chat messages may be processed by a third-party AI model provider (Anthropic) solely to produce
  those summaries and replies.
- Data is not sold, shared with advertisers, used for advertising, or used to train models by the operator.

## Storage and retention

Data is stored only in storage the operator controls (a local database and the operator's private cloud resources).
It is kept until the operator deletes it.

## Your choices

- Google access can be revoked at any time at <https://myaccount.google.com/permissions>.
- Because the only Google account involved is the operator's own, there is no third-party user data to request,
  export, or delete.

## Google API Services User Data Policy

Consigliere's use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Contact

Questions about this policy: open an issue in this repository or contact the operator through their GitHub profile.
